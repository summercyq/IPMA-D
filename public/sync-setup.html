Google 登入與進度同步

網站管理者完成以下設定一次後，各裝置登入同一個 Google 帳號即可同步。使用者不需要自行建立 Firebase 專案。

  1. 在 Authentication 登入方式啟用 Google，選擇專案支援電子郵件並儲存。
  2. 在 Authentication → 設定 → 授權網域，加入 summercyq.github.io。本機開發測試另需加入 localhost。
  3. 確認已建立 Firestore 的預設資料庫 (default)。
  4. 在 Firestore → 規則，將下方規則完整貼上並按「發布」。這是資料庫規則，不是 GitHub 程式碼。
  5. 回到網站按「Google 登入」，再按「立即同步」。看到「已同步」後，用另一台裝置登入同一帳號，核對作答、收藏及筆記。

Firestore 規則

每個帳號只能讀寫自己的 progress/{uid}，其他路徑預設不開放。不應改為允許所有人讀寫。

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /progress/{userId} {
      function isOwner() {
        return request.auth != null && request.auth.uid == userId;
      }
      function validProgress() {
        return request.resource.data.keys().hasOnly(['version', 'clearedAt', 'records', 'updatedAt'])
          && request.resource.data.version == 1
          && request.resource.data.clearedAt is list
          && request.resource.data.clearedAt.size() == 2
          && request.resource.data.clearedAt[0] is int
          && request.resource.data.clearedAt[0] >= 0
          && request.resource.data.clearedAt[1] is string
          && request.resource.data.records is map
          && request.resource.data.records.size() <= 343
          && request.resource.data.updatedAt == request.time;
      }
      allow get: if isOwner();
      allow list: if false;
      allow create, update: if isOwner() && validProgress();
      allow delete: if isOwner();
    }
  }
}

紀錄如何合併

  • 第一次登入會把此裝置既有本機紀錄合併至該帳號。相同欄位以較新的修改為主；不同欄位分開保留。
  • 離線可繼續作答。保持登入，連線恢復或重新開啟頁面後會補傳。請確認狀態顯示「已同步」，再清除瀏覽器資料。
  • 登出後回到獨立的本機模式，不顯示上一帳號紀錄。未同步內容仍保留於此裝置的原帳號，重新登入同帳號後再補傳。
  • 登入後的「重設紀錄」也會清除其他裝置的同步進度，請先確認再使用。
  • 若顯示沒有權限，請確認已發布規則；若顯示授權網域錯誤，請確認 Authentication 的網域設定。手機請使用 Safari 或 Chrome 等一般瀏覽器，避免社群 App 內建瀏覽器。

跨裝置同步需要網路及 Firebase 服務。筆記很長或超出服務額度時可能無法上傳，網站會保留本機內容並顯示錯誤。
